OVA-D LAB v0.5 — Scene Library

Multi-scene authoring workspace.

- Existing v0.4 Tavern state migrates automatically.
- Each scene owns a background asset reference and its own semantic spots.
- Switch scenes without exporting/wiping the previous one.
- + SCENE creates a scene with one neutral UNNAMED / UNSET spot.
- SAVE PROJECT stores the whole workspace locally.
- COPY SCENE exports the active scene.
- EXPORT PROJECT exports the complete scene library.
- IMPORT accepts v0.5 scene/project JSON and older scene-state JSON.
- RESET SCENE resets only the active scene's spots.
- Legacy Tavern route buttons are retired.

Scene Stage owns geography. World connections, routes, and agendas remain separate systems.
